Matte V1.2.1 — Silver Gate

TAG: matte-v1.2.1 · THE "LET ME CLICK THAT" PATCH

The fix

A quick but important one: in V1.2's new single-row top bar, the address bar stopped responding to clicks. The culprit — the top bar is a window-drag region (so you can move the window by grabbing empty space), and it was swallowing mouse events meant for the omnibox inside it.

What changed

  • The omnibox is now marked no-drag, so clicks, focus and text selection all work again
  • Nothing else changed — same peak top bar, same Jarvis, same everything

Why it mattered

It was the first time Matte's built-in update system earned its keep: everyone on V1.2.0 got the "update available" banner automatically the moment 1.2.1 shipped. Found it, fixed it, shipped it — all in one session.
