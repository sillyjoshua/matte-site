Matte V1.1 — Silver Gate

TAG: matte-v1.1-silvergate · THE BRAIN UPDATE

Matte learns to take care of itself

If V1.0 gave Matte its face, V1.1 gave it a brain. This release added a full Settings panel, deep customization, and the ability to update itself — turning a promising browser into one you could actually live in.

What shipped

  • Settings panel — a glassy overlay with everything in one place
  • Four themes — Silver Gate, Midnight, Nord and Light Gate, saved across restarts
  • Custom CSS — a built-in editor to restyle the entire browser interface, persisted locally
  • URL launching — run Matte.exe https://anysite.com to open straight onto a site
  • Automatic update checks — Matte queries GitHub releases on startup and shows a banner when a new version exists, with the version read straight from the installer filename
  • Google as the default search engine, with the smart omnibox
  • Install options for everyone: the .exe installer, or a full Git-from-source tutorial in the README

Growing pains, handled

V1.1 also had its share of iteration: a settings overlay that refused to stay hidden (a one-line CSS lesson about the hidden attribute vs display) was squashed, and the update checker was made smarter by reading versions from the installer asset instead of release tags.

Why it mattered

V1.1 made Matte yours — your theme, your CSS, your keybindings of habit — and made sure it could keep itself fresh. The self-update system built here is the same one that will notify every user the moment V2 lands.
