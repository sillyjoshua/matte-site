Matte V1.0 — Silver Gate

TAG: matte-v1-silvergate · THE BEGINNING

The face of Matte

V1.0 was where it all began — the first public release of Matte, a sleek desktop browser built on Electron with a custom-built interface called Silver Gate. No frameworks, no bloat, just a browser that looked like someone actually cared about how it felt.

What shipped

  • The original Silver Gate UI — dark, glassy, with rounded tabs and a pill omnibox
  • Frameless window with integrated custom title-bar controls
  • Full multi-tab browsing — Ctrl+T, Ctrl+W, Ctrl+Tab all worked from day one
  • Smart omnibox — search DuckDuckGo or navigate directly
  • Navigation done right — back / forward / reload with a live page-load progress bar
  • Secure by default — context isolation, no Node integration in pages
  • Installable via a real .exe installer or from source with Git

Why it mattered

V1.0 proved the concept: a one-person browser project could look and feel as polished as the big ones. Everything after this release — Jarvis, themes, self-updates — stands on the foundation laid here.
