Everything you need. Nothing you don't.

🎨

Silver Gate UI

A dark, glassy interface with pill tabs, a glowing omnibox and buttery animations. Four built-in themes.

🧠

Jarvis

Type jarvis go to github and you're there. Local commands are instant; connect your own AI key for the rest.

🗂

Real multi-tab

Rounded pill tabs with loading dots, middle-click close, Ctrl+T / Ctrl+W / Ctrl+Tab — all the muscle memory works.

🔒

Private by design

Context isolation, no node in pages, no telemetry, no accounts. Your keys and settings stay on your device.

✨

Custom CSS

A built-in editor to restyle the entire browser. If you can write CSS, you can make Matte yours.

🚀

Self-updating

Matte checks GitHub for new releases and tells you when it's time — one click to the installer.

Say it. Matte does it.

Jarvis lives in the address bar. No plugins, no setup required for everyday commands.

› jarvis go to google
→ Navigating to google.com
› jarvis search best browsers 2026
→ Searching Google for "best browsers 2026"
› jarvis open youtube
→ Navigating to youtube.com

Ready when you are.

Grab the installer, or clone the source and build it yourself in three commands.

Download Matte Git tutorial
$ git clone https://github.com/sillyjoshua/matte.git
$ cd matte && npm install
$ npm start
